# Portable Agent Skills (agentskills.io)

The Dev Kit skills are under **`software-development/`** so Hermes lists them in that category. Each skill directory contains **`SKILL.md`** plus optional bundled files ([Agent Skills](https://agentskills.io/specification)).

Point any compatible agent at this folder (or copy skills into your agent’s skills directory). Run PowerShell invokers from the parent **`agent-skills`** repository root.

See [Agent Skills compatibility](../docs/agent-skills-compatibility.md).
